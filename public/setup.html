配置向导

填写你自己的飞书表格与邮箱即可开始。配置只会保存到本机 .env，不会上传任何地方。

① 依赖检测

lark-cli 必装；claude / codex 至少装一个（用于生成草稿与分析）。

② 飞书登录

本系统用你本机 lark-cli 的登录身份访问飞书。请在终端执行下面命令完成一次登录（会弹出授权链接/二维码）：

lark-cli auth login --scope "bitable:app drive:drive mail:user_mailbox.message mail:user_mailbox.message:send"

③ 你的飞书表格与身份

可直接粘贴浏览器里打开表格的完整 URL，自动解析 base token / table / view。
